# YouTube demonstration script / checklist

1. Introduce Smart-X, course and three project phases.
2. Show solution structure in Visual Studio: API, MVC client and xUnit tests.
3. Demonstrate successful build and tests (only if verified).
4. Open the dashboard, register a sensor and submit telemetry via Swagger.
5. Open command history and queue a simulated action; clarify that this is not physical ESP32 delivery.
6. Open network topology, add weighted links, identify disconnected sensors and show the MST.
7. Trace a gateway-to-device route and query historical telemetry by time.
8. Explain graph, BFS, priority queue / Prim MST, AVL balancing and duplicate timestamps.
9. Show README, report, feedback log and GitHub commit history.
10. Upload video and paste real URL into the submission portal.
