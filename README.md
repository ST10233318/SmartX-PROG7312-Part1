Smart-X IoT Data Ingestion Gateway

Project Overview

Smart-X is an IoT Data Ingestion Gateway designed to receive, process, validate, and expose data generated by smart devices and IoT sensors.

The system provides a central API for registering sensors, receiving telemetry data, monitoring sensor information, and managing uploaded device-related files. It also includes a client application that consumes the API and provides a user-facing interface for interacting with the Smart-X platform.

The project demonstrates modern C# and .NET development practices, RESTful API design, object-oriented programming, collections, advanced C# concepts, automated testing, and containerisation using Docker.

How to Run

1. Clone the Repository

Clone the project from GitHub:

git clone https://github.com/ST10233318/SmartX-PROG7312-Part1.git

Navigate into the project:

cd SmartX-PROG7312-Part1

2. Open the Solution

Open the solution in Visual Studio 2026:

SmartX.slnx

3. Restore Dependencies

From the project directory, run:

dotnet restore

4. Build the Solution

dotnet build

5. Run the API

Navigate to the API project:

cd SmartX.Api

Run:

dotnet run

The API will start using the configured ASP.NET Core launch settings.

6. Run the Client

Open a second terminal and navigate to the client project:

cd SmartX.Client

Run:

dotnet run

The client can then be accessed using the URL displayed by ASP.NET Core.

API Endpoints

Sensors

Get Sensors

GET /api/sensors

Returns the registered sensors available in the Smart-X system.

Register Sensor

POST /api/sensors/register

Registers a new sensor/device with the system.

⸻

Telemetry

Get Telemetry

GET /api/telemetry

Returns available telemetry data.

Submit Temperature Telemetry

POST /api/telemetry/temperature

Receives temperature readings from IoT devices.

Submit Power Telemetry

POST /api/telemetry/power

Receives power-related telemetry data.

Submit Switch Telemetry

POST /api/telemetry/switch

Receives switch-state telemetry from supported devices.

⸻

Dashboard

Get Dashboard Data

GET /api/dashboard

Returns dashboard information used to monitor the IoT environment.

⸻

Uploads

Upload Device Data

POST /api/uploads/{deviceId}

Uploads a file or device-related information associated with a specific device.

Docker

Smart-X API includes a Docker configuration for running the API inside a container.

Build the Docker Image

From the SmartX.Api directory:

docker build -t smartx-api .

Run the Docker Container

Run the container using:

docker run -p 8080:8080 smartx-api

The API will then be available on:

http://localhost:8080

The Docker container uses:

ASP.NET Core
.NET 10
Port 8080

The Dockerfile uses a multi-stage build to restore dependencies, build the application, publish the application, and run the final application using the smaller ASP.NET runtime image.

⸻

Docker Configuration

The API contains:

SmartX.Api/
├── Dockerfile
└── .dockerignore

Dockerfile

The Dockerfile:

1. Uses the .NET 10 SDK image for building.
2. Restores NuGet dependencies.
3. Copies the application source code.
4. Builds the application in Release mode.
5. Publishes the application.
6. Uses the .NET 10 ASP.NET runtime image.
7. Exposes port 8080.
8. Starts SmartX.Api.dll.

.dockerignore

The .dockerignore file prevents unnecessary files such as build output and development files from being copied into the Docker build context.
